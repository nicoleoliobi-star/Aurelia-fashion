# AURELIA FASHION

### Elegance in Every Outfit.

## About the Project

Aurelia Fashion is a fashion boutique website created to showcase stylish clothing and fashion accessories. The website provides visitors with information about the boutique and allows them to explore different fashion collections.

## Website Features

- Home page introducing Aurelia Fashion.
- About Us section describing the boutique.
- Separate Products page.
- Fashion collections featuring dresses, casual wear, corporate wear, bags and shoes, and jewelry.
- Contact section with a message form.
- Responsive layout for different screen sizes.
- JavaScript form validation and user feedback.

## Technologies Used

- HTML5 – Website structure.
- CSS3 – Styling and responsive layout.
- JavaScript – Form validation and interactivity.

## Project Structure

## How to View the Website

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in a web browser.

## Project Purpose

This project was developed as part of a web development practical assignment to demonstrate the use of HTML, CSS and JavaScript.
